# Associated Bank: an AI program for commercial bankers

How I'd plan, govern and deliver AI products for Associated Bank's commercial bankers: relationship managers (RMs) and portfolio managers (PMs).

**Start here:** the [Document Library](https://claude.ai/artifact/LTpbCT4kN4LcyEoYnh7vgj), one page listing every document, grouped by section.

- **The plans:** each user group has an executive summary, the product, the plan, a clickable prototype and a detail document. The working copies are in `memos/` (RM files start `rm-`, PM files `pm-`); the prototypes are in `prototypes/`.
- **How we deliver:** the six-step Product Workflow (`memos/role-workflow.md`), the Product Framework (`product-framework.md`), the Product Machine (`product-machine.md`) and the Product Playbook (`playbook/`).
- **The designed pages** are built from these files by the scripts in `designs/` (see `designs/README.md`).
- **How the work is done:** this program is built with Claude as an AI assistant. `CLAUDE.md`, `NOW.md`, `learning/` and `.claude/` hold the rules, lessons and routines it follows, and every change is audited before it goes into the main branch.

Everything about how the bank works today is marked as an assumption to confirm, and every outside figure has a source.
