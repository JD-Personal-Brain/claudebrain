Agent Library

All 40 agents in one place. Each one has a single job, a short list of things it may do, and a named person in charge. Open any card to see its full spec.

These agents help the team run any project through the six steps. They're reused on every project, so they're specified once here: M1 to M19 run the machine's own paperwork and routing, and M20 to M33 do the team's analysis, testing and monitoring work (they started as the RM project's helpers and were made general on 2026-10-10). A project's own agents (the product users see, or agents only that project needs) go in its memo's Appendix A, like A1 to A6 in the RM memo. H1 and on are my own research helpers (see "My research helpers" near the end of the Agent Library page): they keep my reference pages current and are not part of the product machine.

Written with the agent-spec skill. Every agent follows the AI principles in product-framework.md: assistive first, one job each, read-only or draft-only unless a named person approves, and every action logged. Auto agents act only within their listed actions, and those marked ⚠️ wait until the bank allows it.

⚠️ How much to trust this. Written 2026-10-09 from the playbook, not from Associated Bank. "Runs on" tools are guesses from tech-stack.md, and every ⚠️ is a question to confirm at the bank. None of the M agents is built yet; H1 is set up and running.

Two notes on the agents

Agents with an ongoing mode

Four agents keep running after launch, not just once:

  • M13 Data-use checker: it runs again monthly after launch (4.2) and alerts privacy on any difference.
  • M24 Data contract checker: after Define, it runs on every data refresh (3.2) and alerts the data owner on failure.
  • M28 Fairness monitor: set up in 4.4; its ongoing mode re-runs the check monthly after launch (4.4), and fairness is in the monitoring plan (4.8).
  • M32 Quality watchdog: re-runs the test set on every change and at least monthly (6.3), and alerts the product manager when quality slips.

Not agents, but reusable assets

These come up in the review tables but aren't agents. Each one is a template or a library, built once and reused.

  • Story library (2.5): reusable user stories for permissions, logging, feedback and controls.
  • Monitoring plan template (4.8): the standard plan, filled in for each product.
