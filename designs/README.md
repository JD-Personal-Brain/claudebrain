**Shared page kit:** `pagekit.py` holds the house style and the Markdown-to-page code used by `playbook-build.py` and `md-page-build.py`. To give another working file a designed page, add it to `PAGES` in `md-page-build.py`.

**Rendering canvas pages:** no page uses a design canvas since 2026-10-17. If one is added, serve its `.dc.html` files through a local web server (`python3 -m http.server`) with the canvas runtime beside them as `support.js`; `render-check.js` checks any folder that holds a `canvas.json`. To check every page renders fully, run `node designs/render-check.js`.
